CCS 2214 - Data Structures and Algorithms - Task 3
Code files

Q1_Circular_Queue.cpp : circular queue implementation in C++
Q4_Recursion.cpp      : recursive sum, factorial and Fibonacci programs
Q5_Queue.cpp          : ordinary linear queue with enqueue/dequeue
Q6_Sparse_Matrix.cpp  : sparse matrix stored as (row, column, value) triplets
Q7_Deque_C.c          : deque operations in C

Compile using GCC/G++ from the folder containing the files:

  g++ -std=c++17 -Wall -Wextra Q1_Circular_Queue.cpp -o q1
  g++ -std=c++17 -Wall -Wextra Q4_Recursion.cpp -o q4
  g++ -std=c++17 -Wall -Wextra Q5_Queue.cpp -o q5
  g++ -std=c++17 -Wall -Wextra Q6_Sparse_Matrix.cpp -o q6
  gcc -std=c11 -Wall -Wextra Q7_Deque_C.c -o q7

Run on Windows:
  .\q1.exe
  .\q4.exe
  .\q5.exe
  .\q6.exe
  .\q7.exe

Note: Q7 demonstrates the four requested deque operations and includes a small
demonstration in main(). You can add a menu if your lecturer expects interactive input.
